рабочая папка - папка на компьютере, в которой программа хранит файлы с которыми с  сейчас работает
комит - фиксация изменений с пояснениями
индекс - подготовленное состояние файлов для включения в следующий комит
git - программа, которая следит за изменениями в коде
github - сервис для размещения репозиториев, совместной разработки
git status - показывает состояние проекта
git diff - показывает несохраненные изменения
git diff --staged - показывает сохраненные изменения
Ветка — это указатель (ссылка) на конкретный коммит, а не копия файлов. 
Слияние — это создание нового коммита, который объединяет две линии истории. В результате принимающая ветка получает все изменения из вливаемой ветки.
